# Blast+ in Terminal

*#navigate to Blast+ db folder from /Applications to /bin*

$export PATH=$PATH:$PWD

*#Gives temporary access to PATH for current session.*

$makeblastdb -in FILE.fasta -out CRITTERdb -dbtype prot -title “CRITTER” -parse_seqids

*#Creates db files for blasting from fasta parent file.*

*#CRITTERdb and title names must be the same.*

*#Navigate to db folder before issuing blast/n/x command.*

$blastp/n/x -db CRITTERdb -query CRITTER2.fasta -out RESULTS.out -max_target_seqs 1 -max_hsps 1 -evalue 0.05 —outfmt 6 -num_threads 16

*#if given error that blastn/p/x command not found:*

$open -e ~/.zshrc

$export PATH=“/…/bin:$PATH”

$source ~/.zshrc

*#verify the fix:*

$blastn/p/x -version

*#Rerun blastn/p/ command.*

*#If given error that query or argument file is not accessible or that database not found, insert file path ahead of file or db name.*

*#-max_target_seqs 1 returns only best blast hit*

*#-max_hsps 1 returns only best blast hit*

*#-evalue 0.05 sets max e-value to 0.05*

*#-num_threads 16 increases the CPUs used. Can probably remove. Can use 2, 4, or 8 threads in Bifrost as confirmed by PZ*

*#outfmt 6 gives tabular output. 10 here would give csv. Can add qseqid (query seq-id), sseqid (subject seq-id), stitle (subject title0, evalue (e-value), bitscore (bit score). Terminal seems to get mad if custom format includes more than format type (#).*

*#outfmt 10 (csv) changes first query name to query1 but leaves all other query names intact; doesn’t include column titles (qseqid sseqid pident length mismatch gapopen qstart qend sstart send evalue bitscore); gets rid of alignments though*

*#can just leave -outfmt off beyond numerical output style and get all of the above plus start/stop and gap information*

*#More information at https://www.ncbi.nlm.nih.gov/books/NBK279684/*

*#Blast+ help: https://www.youtube.com/watch?v=sMImc_iwX4w*

*#If given error that BLAST Database creation error: Near line #, the local id is too long. Its length is ### but the maximum allowed local id length is 50. Find and correct all local ids that are too long:*

$awk ‘/^>/ {print substr($0, 1, 50); next} {print}’ INPUT.fasta > SHORTENED_INPUT.fasta

*#-parse_sequids has a built in limit of 50 characters including ‘<‘. Either shorten the sequence headers (when seqid not needed for searching) or use the above command to truncate them all at 50 characters (when seqid is needed for searching).*
